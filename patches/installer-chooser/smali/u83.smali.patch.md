# smali hook in the abort handler — say "chosen installer", not "cancelled"

Target file: `smali/u83.smali`, method `x(Lud;Ljava/lang/String;Ljava/lang/String;)V` — that is the
obfuscated `handleInstallationAborted(packageName, error)` (log tag `AppBloc`), the method the app
runs when an install wait settles without a result.

The hand-off flow has no `PackageInstaller` session, so the app's wait ends in the abort handler
after the (shortened) timeout. Without this patch the user would see the stock
"Installation cancelled by user" toast; with it they get a message that matches what actually
happened.

Three edits inside that method:

1. Bump the local count (1 extra register for the package name):

```smali
.method public static final x(Lud;Ljava/lang/String;Ljava/lang/String;)V
    .locals 2
```
→
```smali
.method public static final x(Lud;Ljava/lang/String;Ljava/lang/String;)V
    .locals 3
```

2. Keep the package name before it is overwritten by the toast string. After
`invoke-static {p0, p1, p2}, Lu32;->Z(...)` (the status update) insert:

```smali
    invoke-static {p0, p1, p2}, Lu32;->Z(Lud;Ljava/lang/String;Lfi;)V

    move-object v2, p1
```

3. Replace the toast string when a handoff happened. Find:

```smali
    invoke-virtual {p1, p2}, Lhm2;->a(I)Ljava/lang/String;

    move-result-object p1

    invoke-virtual {p0, p1}, Lud;->r(Ljava/lang/String;)V

    iget-object p0, p0, Lud;->i:Lvf;
```
and replace with:

```smali
    invoke-virtual {p1, p2}, Lhm2;->a(I)Ljava/lang/String;

    move-result-object p1

    invoke-static {v2}, Lcom/revanced/net/revancedmanager/patch/InstallerChooserPatcher;->consumeHandoff(Ljava/lang/String;)Z

    move-result v1

    if-eqz v1, :goto_patch_handoff_toast

    iget-object v1, p0, Lud;->g:Landroid/content/Context;

    invoke-static {v1, v2}, Lcom/revanced/net/revancedmanager/patch/InstallerChooserPatcher;->handoffToastText(Landroid/content/Context;Ljava/lang/String;)Ljava/lang/String;

    move-result-object p1

    :goto_patch_handoff_toast
    invoke-virtual {p0, p1}, Lud;->r(Ljava/lang/String;)V

    iget-object p0, p0, Lud;->i:Lvf;
```

`Lud` is the (obfuscated) AppBloc class; `Lud;->g` is its `android.content.Context` field. The
`consumeHandoff` call also clears the per-package flag so a later real install of the same package
is unaffected.
